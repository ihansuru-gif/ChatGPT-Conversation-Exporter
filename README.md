# ChatGPT Conversation Exporter

ChatGPT 대화를 드래그 복사하지 않고 Markdown 또는 TXT로 추출하는 Chrome/Edge 확장입니다.

## 설치

1. Chrome 또는 Edge에서 `chrome://extensions` 또는 `edge://extensions`를 엽니다.
2. `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. `D:\ChatGPT_Conversation_Exporter` 폴더를 선택합니다.

## 사용

1. `https://chatgpt.com` 또는 `https://chat.openai.com`에서 원하는 대화를 엽니다.
2. 브라우저 상단의 확장 아이콘을 누릅니다.
3. `Markdown 복사`, `Markdown 저장`, `TXT 저장` 중 하나를 선택합니다.

## 참고

- 화면 드래그 선택을 쓰지 않고 페이지의 메시지 구조를 읽습니다.
- ChatGPT 화면 구조가 크게 바뀌면 추출 규칙을 업데이트해야 할 수 있습니다.
- 공유 링크 페이지나 아직 로딩 중인 페이지에서는 메시지를 못 찾을 수 있습니다.
